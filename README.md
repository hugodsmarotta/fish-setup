## Fish Setup

*A simple and opinionated script to set up [Fish Shell](https://fishshell.com)
with sensible defaults.*

> [!NOTE]
> This script was developed for my personal use. If you are not me, please fork
> this repository and tweak it to suit your needs.

### 🚀 How to use

First, make sure you have `curl` and `fish` installed. After that, open a
terminal and run the following command:

```sh
sh -c "$(curl -sSL https://dub.sh/fish-setup)"
```
